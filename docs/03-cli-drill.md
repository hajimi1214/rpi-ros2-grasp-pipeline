# Linux 命令清单（今晚就能开始练）

明天才装 Ubuntu，但这些命令**今晚在 Git Bash 里就能练**，明天直接复用，省一天。

Git Bash 是 Windows 里的一个小型 Linux 环境，路径写法不同（`/c/Users/...` 而不是 `C:\...`），但命令 95% 一样。

---

## 第一档：活下来（必须肌肉记忆）

| 命令 | 干什么 | 练法 |
|------|--------|------|
| `pwd` | 我在哪 | 敲一下 |
| `ls -la` | 当前目录有什么（含隐藏文件） | 敲一下 |
| `cd 目录名` | 进目录 | 进 Downloads 再回来 |
| `cd ..` | 退上一级 | |
| `cd ~` | 回家目录 | |
| `mkdir -p a/b/c` | 建多级目录 | 建一个测试目录 |
| `rm -rf 目录名` | 删目录（**危险，先看清楚路径**） | 删掉刚才建的 |
| `cp -r 源 目标` / `mv 源 目标` | 复制 / 移动 | |
| `cat 文件` | 看整个文件 | 看 README |
| `less 文件` | 翻页看（q 退出） | |

## 第二档：找东西（ROS2 天天用）

| 命令 | 干什么 |
|------|--------|
| `grep -rn "关键词" .` | 在当前目录所有文件里搜关键词（**找 ROS2 报错来源的神器**） |
| `find . -name "*.py"` | 按名字找文件 |
| `ps aux \| grep 进程名` | 看某个进程在不在跑 |
| `kill -9 PID` | 强杀进程 |
| `top` / `htop` | 看 CPU 内存占用（测指标要用） |
| `df -h` | 磁盘还剩多少 |
| `ip a` | 看本机 IP（**多机组网第一步**） |
| `ping IP` | 测通不通 |

`|` 是管道，把前一个命令的输出喂给后一个。这个符号必须会用。

## 第三档：明天装完立刻要用

| 命令 | 干什么 |
|------|--------|
| `ssh 用户名@IP` | 从 PC 远程登录树莓派（**不用给 Pi 接显示器**） |
| `scp 文件 用户名@IP:~/` | 传文件到 Pi |
| `sudo apt update && sudo apt upgrade -y` | 更新系统 |
| `sudo systemctl status 服务名` | 看服务状态 |
| `journalctl -u 服务名 -f` | 看服务日志（ROS2 节点挂了靠这个查） |
| `nano 文件` | 最简单的编辑器（Ctrl+O 保存，Ctrl+X 退出） |

## 今晚的练习任务（20 分钟）

在 Git Bash 里依次做完，做完就算过关：

1. `cd ~` → `pwd` 记下这个路径，明天 Ubuntu 里你会在 `/home/lzy`
2. `mkdir -p ~/drill/test` → `cd ~/drill/test` → `pwd`
3. 用 `echo "hello" > a.txt` 建个文件 → `cat a.txt`
4. `grep -rn "hello" .` 看看能不能搜到
5. `ls -la` 看看 `.` 和 `..` 是什么
6. 回退：`cd ~` → `rm -rf ~/drill`

第 6 步删的是你自己刚建的目录，安全。但**这个 `rm -rf` 的手感要记住**：路径写错一次就是真删。明天在 Ubuntu 上执行前，一定先 `pwd` 确认自己在哪。
