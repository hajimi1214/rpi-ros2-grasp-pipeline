# 路线图：从今天到拿到实习

起点：2026-10（大二上）｜ 目标：2028-02（大三下）投出第一份嵌入式 AI / 机器人软件实习简历

判断标准只有一条：**每个阶段结束时，仓库里多了什么别人能验证的东西。**

---

## P0 地基期 ｜ 2026-10 → 2026-12

目标：让这条链路真的跑通一次，哪怕很丑。

| 交付物 | 完成标志 |
|--------|----------|
| Linux 环境 | PC + Pi5 都装好 Ubuntu 24.04 |
| ROS2 组网 | Pi 和 PC 能互相看到对方的 topic（`ros2 topic list` 双向可见） |
| 端侧推理 | Pi 上跑通一个 ONNX 检测模型，有 FPS 数字 |
| 第一个闭环 | 手机拍到目标 → Pi 推理 → PC Gazebo 机械臂动一下 |

阶段末证据：`docs/demo.gif`（5 秒动图）+ 指标表里前 4 行有真实数字。

## P1 做深期 ｜ 2027-01 → 2027-04

目标：从"能跑"变成"跑得明白"。

- INT8 量化，出 FP32 vs INT8 对比数据
- 多目标 + 目标选择逻辑（不是只会抓一个）
- 抓取位姿估计（不只是框，要有朝向）
- 加 Web 监控页（平板/浏览器看推理画面 + 机械臂状态）
- 可选：STM32 接进来做真实末端执行器（借到的板子）

阶段末证据：一篇写清楚"为什么 INT8 快了多少、精度掉了多少"的技术笔记。

## P2 变硬期 ｜ 2027-05 → 2027-08

目标：从"项目"变成"能扛追问的项目"。

- 抓取成功率统计（不少于 50 次，带域随机化）
- 延迟预算拆解：摄像头采集 / 网络传输 / 推理 / 控制各占多少毫秒
- 故障记录：断流怎么办、检测丢失怎么办、机械臂超时怎么办
- 把踩过的坑写成博客（这也是证据）

阶段末证据：`docs/` 下有完整指标表 + 至少 2 篇对外可见的技术文章。
