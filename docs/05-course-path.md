# 课程路线：看哪些、跳过哪些

> ⚠️ **2026-10-12 更新：主项目已换成 r2net（ROS2 连接诊断 CLI），学习主线随之改变。**
> 本文档的 TF2 / URDF / MoveIt2 部分**降级为副线**，主线见 **`docs/10-learning-path.md`**（DDS 与通信底层）。
> 下面的"跳过导航/SLAM"和"第 1 门核心概念"依然有效。

## ⚠️ 先看这条：主流 ROS2 课的 60% 内容对本项目的废的

市面上绝大多数 ROS2 中文课是**移动机器人导向**——小车底盘、激光雷达、SLAM 建图、Navigation2 导航。

**这些对你全是废的**，两个原因：
1. 你的项目是**操作类（抓取）**，不是移动类。JD 里明确写着"仅有导航/SLAM 经验者不匹配"。
2. 学了也用不上，白花几十小时。

**所以每门课只看前 1/3（核心概念段），讲到小车/雷达/建图/导航就停。**

## 主线课程（按顺序）

### 第 1 门：ROS2 核心概念 —— 现在就上

| 课程 | 位置 | 说明 |
|------|------|------|
| **古月居·ROS2 入门 21 讲** | B 站 `BV16B4y1Q7jQ` | 中文 ROS2 最经典的入门，讲概念清楚。图文版 guyuehome.com |
| 鱼香 ROS·动手学 ROS2 | fishros.com/d2lros2/ + B 站 | 更偏动手，作者就是一键安装工具的作者，环境坑讲得多 |
| 赵虚左·ROS2 理论与实践 | B 站 `BV1VB4y137ys` | 社区评价"讲得细"，可当补充 |

三选一即可，**不要三门都看**。推荐古月居入门 → 卡住了再翻鱼香的文档。

**看这些讲（约 6–8 讲，2 小时内）**：
- ROS2 是什么、和 ROS1 的区别（1 讲，了解即可）
- 工作空间与包（workspace / package）
- **节点 Node**
- **话题 Topic**（发布订阅，本项目图像和位姿都走这个）
- **服务 Service** / **动作 Action**（抓取这种"有过程、可打断"的任务用 Action）
- **参数 Parameter**
- **Launch 文件**（一次起多个节点）
- **rqt / ros2 命令行工具**（`ros2 topic list`、`ros2 topic hz`，调试全靠它）

**看到这里就停。**

**明确跳过**：TF2 之后的移动机器人部分、URDF 建模的小车、Gazebo 的小车仿真、SLAM、Navigation2。

---

### 第 2 门：TF2 坐标变换 —— 装完系统后立刻学

ROS2 里"相机看到的坐标"变成"机械臂能用的坐标"全靠 TF2。这是本项目的**中枢**。

- 古月居/鱼香课程里的 TF2 章节
- 判断学会的标准：能说清"像素坐标 → 相机坐标系 → 机械臂基座坐标系"要经过几次变换

---

### 第 3 门：URDF 建模 + MoveIt2 —— 项目真正的核心

机械臂方向的正课，不是小车方向。

| 资源 | 说明 |
|------|------|
| 鱼香 ROS《动手学 MoveIt2》 | 源码 `gitee.com/ohhuo/d2lmoveit2_tutorials`（国内镜像，比 GitHub 快） |
| MoveIt2 官方教程 | moveit2_tutorials，含 **Pick and Place** 示例 —— 就是这个项目要的东西 |
| MoveIt Setup Assistant | 图形化配置机械臂，不用手写 SRDF |

**重点看**：
- URDF/Xacro 怎么写机械臂（关节、连杆、限位）
- MoveIt Setup Assistant 生成配置包
- **Planning Group / 位姿目标 / 规划与执行**
- **Pick and Place 流程**（moveit2_tutorials 里有现成模板）
- 碰撞物体 CollisionObject —— 桌面、目标方块要加进规划场景

**要知道 MoveIt2 不做什么**（这决定了你的活在哪）：
- ❌ 不做目标位姿估计 → **这正是你树莓派端侧推理要干的活**
- ❌ 不做抓取姿态生成（grasp generation）→ 需要自己算或简化
- ✅ 只负责：拿到目标位姿 → 规划无碰撞轨迹 → 执行

> 这条边界极其重要：**MoveIt2 的输入就是你的输出**。你的感知模块给什么格式，MoveIt 就吃什么格式。学的时候盯住这个接口。

## 不用上的课（明确排除）

| 课 | 为什么不上 |
|---|---|
| 系统 Linux 课（韩顺平/尚硅谷，几十小时） | **你有 Linux 运维底子**（部署过 Gitea/禅道、调过 Apache/MySQL）。缺的是命令手感，不是系统知识。用 `03-cli-drill.md` 练 20 分钟就够，边用边查 |
| SLAM / 导航 / Nav2 | 方向不匹配，JD 硬筛项 |
| 深度学习原理 / 算法课 | 明确不做算法，你只需要**会部署** |
| ROS1 | 直接学 ROS2，别回头 |

## 明天装完系统立刻要用的两个社区工具（先记住）

官方安装文档步骤繁琐且国内网络会卡，社区工具更好用——这正是"信踩坑的不信官方的"：

1. **鱼香 ROS 一键安装**（装 ROS2 Jazzy + 换源 + 装 ros2 工具，一条命令）
   ```
   wget http://fishros.com/install -O fishros && . fishros
   ```
2. **rosdepc**：`rosdep` 的国内替代，解决依赖安装慢/失败
   ```
   sudo pip3 install rosdepc
   ```

## 课程进度与项目阶段的对应

| 项目阶段 | 需要学完 |
|----------|----------|
| 明天装完 Ubuntu | 第 1 门（核心概念）+ 用 fishros 一键装好 ROS2 |
| W1 组网 | 无新课，练命令行 |
| W2 端侧推理 | 无新课（Python + ONNX，你已有基础） |
| W3 闭环 | 第 2 门 TF2 + 第 3 门 URDF/MoveIt2 |

**不要提前学第 3 门。** 没装好 ROS2 就看 MoveIt2 会全是抽象概念，看了也白看。
