# 岗位能力差距表

**为什么现在就做**：装 Linux 要花时间，但看靶子不需要任何环境。先知道人家要什么，再决定力气往哪使，才不会学了一堆用不上的东西。

---

## 怎么用

1. 去 Boss 直聘 / 实习僧 / 拉勾，搜这三个词：
   - `嵌入式 AI 实习`
   - `机器人软件 实习`
   - `边缘智能 实习`
2. 挑 **10 个**你看了会觉得"这个我够得着"的岗位，把要求抄进下面的表
3. 抄完统计：哪些能力出现次数最多 → 那就是你接下来 8 个月该砸时间的地方

**只挑"够得着"的**——要求里写"硕士优先""3 年经验"的直接跳过，抄了没意义。

## 判读规则

- **出现 ≥7 次且我没证据** → 最高优先级，接下来 3 个月必须补出可展示的东西
- **出现 4~6 次** → 次要，有空再补
- **出现 ≤3 次** → 不管

---

## 止损点（很重要）

如果 10 个 JD 抄完，发现高频要求里有**超过两项**是你在 8 个月内根本补不出来的（比如普遍要求硕士、要求 CUDA 底层优化、要求有量产经验），那就说明这个方向对本科实习生不友好，需要**现在**就调整方向（Web 全栈 + 运维是你的退路，技能栈已经在手）。

早发现早改，比装完 Linux 做三个月再发现强得多。
